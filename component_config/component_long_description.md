The UKG Pro Workforce Management extractor reads the WFM (formerly Workforce Dimensions / Kronos) API surface: People/Persons, Business Structure, Hyperfind queries, Timekeeping (punches, timecards, timecard metrics), Scheduling (schedules, shifts, open shifts, swaps), Accruals (balances, transactions, summaries), Leave (cases, edits), Attendance (records, events), Attestations, Work/Activities (activities, activity shifts, net-change resources), Payroll async export, and Forecasting.

**Authentication.** Auth is OAuth 2.0 `password` grant (resource-owner) against your tenant vanity host (e.g. `https://mycompany.prd.mykronos.com`), so a dedicated **service account** is required. You supply the host plus four secrets: `client_id`, `client_secret`, `username`, `password`. The `client_id`/`client_secret` are issued by UKG when the tenant is set up, and a tenant Developer Admin must create the service account. The tenant host is a configuration field and is never composed by the component.

**Configuration model.** One configuration row = one resource. The global configuration holds authentication; each row selects a resource, a load type, an optional date window / symbolic period, an optional Hyperfind query (employee scope), and select fields. Incremental resources upsert by primary key and split the fetch window into ≤365-day sub-windows to respect service limits; the window is recomputed from the row's Start/End Date on every run, with no stored watermark. Resources without a stable primary key always run full-load.

**Provisioning note.** There is no public UKG WFM sandbox, so credentials come from a provisioned customer/partner tenant. The endpoint contract has been verified against a live tenant. Two families are documented but not data-verified there: Work/Activities requires the Activities Integration API license (HTTP 403) and Forecasting requires tenant-configured category drivers.
