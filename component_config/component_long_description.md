The UKG Pro Workforce Management extractor reads the full WFM (formerly Workforce Dimensions / Kronos) API surface: People/Persons, Business Structure, Hyperfind queries, Information Access, Timekeeping (punches, timecards, timecard metrics), Scheduling (schedules, shifts, open shifts, swaps), Accruals (balances, transactions, summaries), Leave (cases, edits, requests), Attendance (records, patterns, events), Attestations, Work/Activities (activities, activity shifts, net-change resources), Payroll async export, and Forecasting.

**Authentication.** Auth is OAuth 2.0 `password` grant (resource-owner) against your tenant vanity host (e.g. `https://acme.prd.mykronos.com`), so a dedicated **service account** is required. You supply the host plus four secrets: `client_id`, `client_secret`, `username`, `password`. The `client_id`/`client_secret` are minted by UKG at tenant provisioning and a tenant Developer Admin must create the service account. The tenant host is a configuration field and is never composed by the component.

**Configuration model.** One configuration row = one resource. The global configuration holds authentication; each row selects a resource, a load type, an optional date window / symbolic period, an optional Hyperfind query (employee scope), and select fields. Incremental resources keep a per-row state watermark, split the window into ≤365-day sub-windows to respect service limits, and advance the watermark even when a run returns no rows. Resources without a stable primary key always run full-load.

**Provisioning note.** There is no public UKG WFM sandbox. Live authentication and end-to-end verification are deferred until a customer sandbox tenant with a provisioned service account and minted credentials is available; the component is built against documented API behavior with synthetic test fixtures.
